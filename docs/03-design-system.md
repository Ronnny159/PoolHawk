# Design System - PoolHawk (Estilo Billar Premium)

## 1. Paleta de Colores (Temática de Billar)
- **Fondo (Mesa):** Degradado radial de verde oscuro (#0f172a a #15803d).
- **Paño Iluminado:** #22c55e (Verde neón para turnos activos y éxitos).
- **Bola 1 (Amarilla):** #facc15 (Para el Equipo A).
- **Bola 2 (Azul):** #3b82f6 (Para el Equipo B).
- **Bola 3 (Roja):** #ef4444 (Para faltas y errores).
- **Bola 8 (Negra):** #000000 (Para textos principales o fondos oscuros).
- **Texto:** Blanco roto (#f8fafc) y gris claro (#94a3b8).

## 2. Tipografía
- **Títulos:** 'Bebas Neue' (Sensación deportiva, condensada, mayúsculas).
- **Cuerpo y Datos:** 'Inter' o 'Segoe UI' (Legibilidad limpia).

## 3. Elementos Visuales (UI)
- **Bolas 3D:** Cualquier representación de una bola (marcador o inputs) debe tener un gradiente radial y sombras internas para simular una esfera.
- **Botones:** Deben tener relieve, sombras de caída y transiciones de hover (efecto de presionar un botón físico).
- **Feedback:** Los paneles de éxito deben tener borde izquierdo verde; los de error, borde izquierdo rojo.
